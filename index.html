The Logic Detective: สืบสวนเงื่อนไขภาษาไทย

สถานการณ์เงื่อนไขที่กำหนด โจทย์ระดับสอบ ก.พ.

เงื่อนไขข้อเท็จจริง:

  • ข้าราชการทุกคนที่สังกัดกระทรวงมหาดไทย ต้องผ่านการอบรมหลักสูตรนักปกครองระดับสูง (นปส.)
  • ผู้ที่ผ่านการอบรมหลักสูตร นปส. ทุกคน ได้รับสิทธิ์เสนอชื่อเข้ารับการคัดเลือกเป็นผู้ตรวจราชการ
  • สมชายเป็นข้าราชการสังกัดกระทรวงมหาดไทย แต่ สมศักดิ์ ไม่ได้สังกัดกระทรวงมหาดไทย

ข้อสรุปที่ต้องพิจารณา:

  1. ข้อสรุปที่ 1: สมชายได้รับสิทธิ์เสนอชื่อเข้ารับการคัดเลือกเป็นผู้ตรวจราชการ
  2. ข้อสรุปที่ 2: สมศักดิ์ไม่ได้รับสิทธิ์เสนอชื่อเข้ารับการคัดเลือกเป็นผู้ตรวจราชการ
💡 **คำแนะนำ:** ฝึกพิมพ์วิธีคิดของคุณและระบุว่าข้อสรุป 1 และ 2 เป็น "จริง", "ไม่จริง" หรือ "แน่ชัดไม่ได้" AI จะใช้ Socratic Questioning ในการช่วยตรวจโดยไม่เฉลยคำตอบทันที
โต้ตอบกับ Logic Detective AI Socratic Mode Active
👋 สวัสดีครับ! ลองพิจารณาโจทย์ทางซ้ายมือ แล้วพิมพ์ **วิธีคิดคำนวณตรรกะ** พร้อม **คำตอบของทั้ง 2 ข้อสรุป** มาให้ผมช่วยตรวจเช็กได้เลยครับ

Royal & Bureaucratic Contextualizer: ราชาศัพท์ในบริบทจริง

บทบาทสมมติ (Roleplay Mission)

📋 ภารกิจข้าราชการร่างหนังสือ:

คุณได้รับมอบหมายจากปลัดกระทรวงให้ร่าง **บันทึกข้อความ (หนังสือภายใน)** ถึงปลัดกระทรวง เพื่อขออนุมัติโครงการและขอนำเรียนเชิญ สมเด็จพระกนิษฐาธิราชเจ้า กรมสมเด็จพระเทพรัตนราชสุดาฯ สยามบรมราชกุมารี เสด็จพระราชดำเนินไปทรงเป็นประธานในพิธีเปิด

⚠️ คำเตือน: ระวังระดับชั้นการใช้ราชาศัพท์ (กราบบังคมทูล/เสด็จพระราชดำเนิน) และภาษาราชการระดับผู้บริหาร

คลังคำราชาศัพท์แนะนำสำหรับระดับนี้:
• เชิญเสด็จ -> กราบบังคมทูลเชิญ
• ไปเปิดงาน -> เสด็จพระราชดำเนินไปทรงเป็นประธาน
• มอบให้ -> ทูลเกล้าฯ ถวาย
• ขออนุมัติ -> โปรดพิจารณาอนุมัติ
โต้ตอบกับ ปลัดกระทรวง (Senior Official AI) Strict Grammar Mode
👓 *"สวัสดีครับคุณเจ้าหน้าที่ร่างหนังสือ โปรดส่งร่างบันทึกข้อความส่วนขออนุมัติมาให้ผมตรวจดูความถูกต้องก่อนเสนอปลัดกระทรวงครับ"*

AI-Driven Mock Exam Debriefer: วิเคราะห์จุดอ่อนทางความคิด

Cognitive Gap Analysis
ข้อสอบภาษาไทยที่ทำผิด ข้อสอบภาค ก.พ. Real Exam

โจทย์: ข้อใดใช้สำนวนภาษาไทยได้ถูกต้องตามหลักภาษาราชการ?

ก) สำนักงานเขตได้ทำโครงการนี้ขึ้นมาเพื่อแก้ปัญหาขยะ
ข) ประธานในพิธีมอบเกียรติบัตรแก่ผู้เข้าอบรมทุกคน
ค) กรุณาส่งแบบฟอร์มคืนกลับมายังเจ้าหน้าที่ภายในวันศุกร์
ง) คณะกรรมการกำลังดำเนินการพิจารณาหลักเกณฑ์ใหม่
รายงานวิเคราะห์ข้อบกพร่อง (Diagnostic Report) Remedial Mode

กดปุ่ม "วิเคราะห์รูปแบบความผิดพลาด" เพื่อดูรายงานจุดอ่อนรายบุคคล และรับโจทย์ฝึกซ้อมซ่อมเสริม

คลัง System Prompts สำหรับทั้ง 5 Use Cases

1. Logic Detective System Prompt 
คุณคือ "ผู้เชี่ยวชาญการวิเคราะห์ตรรกะและเงื่อนไขภาษาไทยสำหรับสอบ ก.พ." หน้าที่ของคุณคือช่วยฉันฝึกฝนโจทย์เงื่อนไขภาษาไทยระดับซับซ้อน โดยใช้การตั้งคำถามนำทาง (Socratic Questioning) ไม่เฉลยคำตอบทันที
2. Royal Contextualizer System Prompt 
คุณคือ "ข้าราชการระดับสูง ผู้เชี่ยวชาญระเบียบงานสารบรรณและราชาศัพท์" ให้คุณสวมบทบาทสุ่มสร้างสถานการณ์จำลองงานราชการ และทักท้วงหากผู้เรียนใช้คำราชาศัพท์หรือภาษาราชการผิดลำดับชั้น
